## 앱 콘텐츠 설문 답변

콘솔 화면의 문구는 바뀔 수 있으니 뜻이 같은 항목을 고르세요.

- **개인정보처리방침**: 위 URL
- **앱 액세스 권한**: 모든 기능을 제한 없이 이용 가능(로그인 없음)
- **광고**: 광고 없음
- **콘텐츠 등급**: 카테고리는 "기타 앱 유형". 폭력·성·도박 등은 모두 "아니요". 담배 관련 질문에는 "예"(담배와 흡연 장면이 화면에 나옴)로 답하세요. 금연 목적이라도 숨기지 않는 것이 안전합니다.
- **타겟층**: 만 18세 이상만 선택. 어린이의 관심을 끌 수 있는지 묻는 질문은 "아니요"
- **데이터 보안**: 사용자 데이터를 수집하거나 공유하지 않음
- **건강 앱 신고**: 건강 기능 있음 → "금연/습관 관리"에 가장 가까운 항목 선택. 의료 기기 아님
- **정부 앱 / 금융 기능 / 뉴스 앱**: 모두 해당 없음
