# 한 모금 — 금연 도우미

피우고 싶을 때 진짜 담배 대신 **가상 담배**를 피우며 갈망을 넘기는 금연 앱(PWA)입니다.

- **가상 담배**: 화면을 꾹 누르면 불씨가 달아오르고 연기가 짙어지며 담배가 타들어 갑니다. 손을 떼면 내뿜는 연기가 퍼집니다. 한 개비를 다 태우면 "참은 담배" 1개비로 기록됩니다.
- **기록**: 금연 시간, 아낀 돈, 되찾은 수명, 참은 담배 개비 수, 몸의 회복 단계.
- **설정**: 금연 시작 시각, 하루 흡연량, 한 갑 가격, 소리·진동.

빌드 과정이 없는 정적 웹앱입니다. 데이터는 기기의 `localStorage`에만 저장됩니다.

```sh
python3 -m http.server 8000   # http://localhost:8000
```

휴대폰에서는 HTTPS로 배포한 주소를 열고 "홈 화면에 추가"를 하면 앱처럼 쓸 수 있습니다.
